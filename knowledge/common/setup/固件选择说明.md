# WX5860 / WX5886 固件包选择说明

## 目录结构约定

通用固件位于 knowledge/common/setup/<型号>/，每个型号下五类目录：
boot（u-boot 镜像）、kernal（内核 uImage）、dtb（设备树）、fs（根文件系统）、app（驱动 ko 与测试程序）。
镜像文件名即配置：u-boot-<网口>-ddr<位宽>[-sf|-test].img，dtb 为 kd<型号>_<网口>_<fs类型>.dtb。

## WX5860（kd5860）

- 网口：仅 RGMII；dtb 两种：kd5860_rgmii_jffs.dtb（jffs2 根文件系统）、kd5860_rgmii_ramfs.dtb（ramfs 直载）
- boot：u-boot-wx5860.img；另有 DDR 频点版本 output800M/1066M/1333M/1600M 同名镜像
- kernel：uImage_kd5860（jffs2 用）、uImage_ramfs_kd5860（ramfs 用）
- fs：jffs2_kd5860.img；app：ramfs_umdevxs_k.ko / jffs2_umdevxs_k.ko，loadsoc.sh / unloadsoc.sh 加载卸载，pie_tx 为以太网发包测试，memxs/coremark 为内存与性能测试

## WX5886（kd5886）

- 网口：GMII 与 RGMII 两种；dtb：kd5886_<gmii|rgmii>_<jffs|ramfs|etx4>.dtb（etx4 为四口以太网）
- boot：u-boot-<gmii|rgmii>-ddr<16|32>[-sf].img，-sf 表示 SPI-NOR 启动，非 sf 为大容量 NAND；另有 -test 调试版
- DDR 频点：output800M/1066M/1333M/1600M 四套 boot 子目录，与 5860 同规则
- kernel：uImage_kd5886、uImage_ramfs_kd5886；fs：jffs2_kd5886.img、rootfs_kd5886.ext4
- app：emmc_umdevxs_k.ko（eMMC）、jffs2_umdevxs_k.ko、ramfs_umdevxs_k.ko + loadsoc/unloadsoc + pie_tx/memxs/coremark

## DDR 频点如何确认

boot/readme.txt：增加 DDR 800M/1066M/1333M/1600M 工作主频支持，可根据 U-Boot 启动打印信息获取 DDR 工作主频；没有打印的都是缺省 1600M。

## 常见组合速查

| 场景 | boot | dtb | kernel | fs |
|------|------|-----|--------|----|
| 5860 + jffs2 调试 | boot/output1600M/u-boot-wx5860.img | dtb/kd5860_rgmii_jffs.dtb | kernal/uImage_kd5860 | fs/jffs2_kd5860.img + jffs2_umdevxs_k.ko |
| 5860 无 fs 快速验证 | 同上 | dtb/kd5860_rgmii_ramfs.dtb | kernal/uImage_ramfs_kd5860 | ramfs_umdevxs_k.ko |
| 5886 RGMII NAND | boot/u-boot-rgmii-ddr32.img | kd5886_rgmii_jffs.dtb | uImage_kd5886 | jffs2 或 ext4 |
| 5886 SPI-NOR 启动 | boot/u-boot-rgmii-ddr16-sf.img 或 gmii-sf | 按网口选 | uImage_kd5886 | jffs2_kd5886.img |
