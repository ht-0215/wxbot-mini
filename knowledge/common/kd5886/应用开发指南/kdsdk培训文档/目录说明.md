# 目录说明

SDK 目录说明：

| kyland_api-VXXXX | 交换芯片驱动，提供芯片驱动级API .内部platform为支持各种硬件平台的代码。 |
| --- | --- |
| phy | PHY 模块,支持所有PHY管理，提供PHY驱动API. |
| common | 一些通用代码，与硬件无关 ，共其它模块使用，如sal系统适配代码,一些常用的函数,功能模块等。 |
| kd | 硬件抽象层，向上屏蔽硬件信息，向下兼容各种型号的硬件.提供简单,易用,通用的API。属于业务级API。 |
| Appl | 应用层代码，使用抽象层KD api完成业务功能，禁止直接使用驱动级 API。 |
| Doc | 用户级文档。 |
| system | 系统相关文件。 |
| output | 生成目标文件目录。*.o,*.a,等 |
| Make | Makefile相关的文件,实现统一编译管理. |
| Realese | 发布版本备份目录 |
